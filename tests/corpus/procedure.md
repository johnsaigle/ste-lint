# Replace the filter

1. Stop the pump before opening the valve.
2. The valve is opened by the operator.
3. Remove the cover; then remove the filter.
4. The filter must be replaced every month.
5. Make sure that the seal is not damaged.
6. The new filter should have been inspected by the supplier.
7. Install the new filter.
8. The pump is started again when the cover is installed.

Moreover, the pump is a robust unit.
Obviously, a broken seal is a problem.
The seal was found by the technician during the inspection.
The seal is unchanged.
The pressure is set to 4 bar.
The hose is held in place with a clamp.
